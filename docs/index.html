Made for the in-between moments

One small place for four useful things.

Desktop agent

Ask, then follow up.

Get help with Omarchy or ask the agent to handle a bounded desktop task. Follow-ups share a conversation until you start a new one or it expires after idle time.

Local notes

Keep a Scratchpad.

Save paths, prompts and half-written thoughts locally. Your notes stay separate from AI requests unless you choose to use them.

Capture

Capture the moment.

Take a screenshot or start a recording from the bar. Copy a file path or attach a screenshot to a note. View the actual captured image.

Voice, when you want it

Speak a draft.

With optional Voxtype, click the mic to dictate or hold it to talk. Review the draft before you press Send.

Know what you're running

A desktop agent with your permissions.

Ask Omar runs as your user. It can read files, run programs and use the network. Ask First shows the exact shell command with Allow once, Allow for this question or Deny. Block Commands disables Omar’s shell command tool; explicitly enabled Allow All runs shell commands without asking. This is not a sandbox. Stopping a task does not undo actions already completed.

AI requests use Pi and the provider you connect inside Pi. Ask Omar does not install Pi or handle your provider sign-in. Notes, drafts and recent answers stay local; task context may be sent to your provider.
