# Roadmap

## In 0.1

- Omarchy bar entry, compact answer panel and follow-up conversations
- Ask First / Block Commands / Allow All modes, Stop and New
- Local Scratchpad and recent answers
- Capture shortcuts and optional Voxtype drafts
- Provider/model/reasoning settings through Pi

## Next: make the small workflow dependable

- Broader clean-user and multi-monitor testing
- Smaller QML components with runtime UI coverage
- Explicit attachment cleanup and improved log rotation
- More reliable progress for long tasks
- Accessibility and keyboard polish based on actual use

## Exploring, not promised

A separate session launcher may eventually let a user choose a repository, skills and a genuinely isolated execution environment. It would require an explicit reviewable launch step and independently enforced filesystem/network boundaries. A local process alone is not a sandbox.

Ask Omar will remain the desktop entry point. There is no delivery date for this work, and none of it is part of 0.1.
